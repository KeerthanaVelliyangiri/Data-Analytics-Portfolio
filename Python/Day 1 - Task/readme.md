##  Python Environment

Python version can be checked using:

```bash
python --version
```

Pip can be checked using:

```bash
pip --version
```

### Virtual Environment

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

The virtual environment provides an isolated environment for the project.

##  Tasks

### Task 1 – Installation & Environment

Verifies the Python installation, Python version, pip availability, and virtual environment setup.

### Task 2 – Variables & Syntax

Stores and displays student details such as name, ID, department, age, and semester. It also demonstrates Python syntax and indentation.

### Task 3 – Operators

Performs calculations using arithmetic operators and demonstrates comparison, logical, and assignment operators.

### Task 4 – Type Casting

Converts values between data types using `int()` and `float()` and verifies the data types using `type()`.

### Task 5 – Student Profile

Combines the concepts learned in the previous tasks to create a simple student profile program.

##  How to Run

After activating the virtual environment, run each file using:

```bash
python task_01_installation.py
python task_02_variables.py
python task_03_operators.py
python task_04_type_casting.py
python task_05_student_profile.py
```
