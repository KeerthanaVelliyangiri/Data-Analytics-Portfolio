ResumeSync starter project

1. Extract the ZIP.
2. Open a terminal in the ResumeSync folder.
3. Create and activate a Python virtual environment.
4. Run: pip install -r requirements.txt
5. Copy .streamlit/secrets.toml.example to .streamlit/secrets.toml and add your API keys.
6. Run: streamlit run app.py

Read README.md for details and limitations.
